# 📟 RetroOS AI

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**RetroOS AI** is an interactive simulated retro Unix/DOS terminal environment built for **POLLEN-QUEST #19179** where a **Pollinations.ai** language model plays the part of an entire virtual computer, executing shell commands, file systems, and text adventure games.

## 🌐 Live Web App
- **Live Demo:** [https://lekezoa.github.io/pollinations-retro-os-ai/](https://lekezoa.github.io/pollinations-retro-os-ai/)

## 🚀 Features
- **Simulated Machine Architecture:** The AI plays the operating system kernel, filesystem, and utilities (`ls`, `cat`, `uname`, `ps`, `adventure`).
- **Interactive CRT Terminal:** Authentic green-phosphor retro terminal styling with instant command execution.
- **Dynamic Story Games:** Run text adventures and interactive utilities entirely hallucinated by Pollinations models.
- **Bring Your Own Pollen (BYOP):** Integrated API key support for users to power terminal sessions with their own balance.

## 🛠️ Built With
- **Pollinations.ai API:** `https://gen.pollinations.ai/v1/chat/completions`
